# 2026 andgopink ambient soundsystem 🎹

Персональный блог Андрея Скородумова. Живописный академизм, эмбиент-акустика и эстетика электронной культуры.

## О проекте
Сайт работает на генераторе статических сайтов [Hugo](https://gohugo.io) с использованием легковесной темной темы [Bear Cub](https://github.com).

* **Домен:** [pink01.ru](https://pink01.ru)
* **Хостинг:** GitHub Pages (сборка через GitHub Actions)

## Как устроен репозиторий
* `/content` — ваши статьи и посты в формате Markdown (`.md`).
* `/static/images` — картинки и фотографии, используемые в публикациях.
* `/themes/hugo-bearcub` — исходный код оформления темы.
* `hugo.toml` — главный конфигурационный файл сайта.
